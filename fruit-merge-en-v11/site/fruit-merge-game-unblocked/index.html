What does “unblocked” mean?

It describes a game page that can be reached on the network and device you are using. It is not a guarantee of access. A school, workplace or device administrator may restrict game websites, and this page does not bypass those restrictions.

If the game does not load

Use an up-to-date browser with JavaScript enabled. Check your connection and try reloading the page. If your network blocks games, use a permitted network or ask the administrator about access.

Keep playing without an account

The game does not require registration. Completed juice records are saved in your current browser, so they may not appear on another device. You can change the Name field at any time; each result keeps the name used when it was saved.
